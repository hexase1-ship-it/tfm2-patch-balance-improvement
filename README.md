# TFM2 Patch Balance Improvement

Public update manifest for the Teamfight Manager 2 internal balance patch distribution.

Manifest URL:

```text
https://api.github.com/repos/hexase1-ship-it/tfm2-patch-balance-improvement/contents/UPDATE_MANIFEST.json?ref=main
```

The updater also accepts plain raw JSON manifests, but the GitHub Contents API
URL avoids short-lived raw CDN staleness after replacing release assets.

Release ZIPs are attached to GitHub Releases.
